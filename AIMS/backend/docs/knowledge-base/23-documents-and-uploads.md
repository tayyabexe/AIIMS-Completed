# Documents and uploads

## What the Documents screen is for

Identity and academic documents belonging to a student: CNIC or B-Form,
previous transcripts, certificates, photographs. It is a record store, not a
coursework drop box.

Students reach it at **Documents** (`/student/documents`).

## What it is not for

Assignment submissions. AIMS has no coursework submission feature — see
*Assignments*. Uploading a completed assignment here does not submit it to
anyone and no teacher is notified.

## Who can see a student's documents?

The student themselves, and administrative staff. A student sees only their
own, always.

Teachers do not use this screen for their classes; a teacher who needs a
document for a student goes through the administration office.

## Uploading

From **Documents**, choose the document type and the file. The file is stored
inside AIMS itself rather than as a loose file on a server, so it travels with
the record and cannot be orphaned by a server rebuild.

## Profile pictures

A profile picture is stored on the account, not as a document, and is changed
from the **Profile** screen in each portal. Replacing it replaces the previous
one; there is no history of past pictures.

## Deleting a document

A student can remove a document they uploaded. Administrative staff can remove
one from a student's record.

Removal is a record change and is written to the audit log where staff did it.

## Common questions

**Why was my upload rejected?** The two usual reasons are an unsupported file
type and a file over the size limit. The error names which.

**Can I upload a document for another student?** No. A student's upload is
attached to their own account by the session, not by a field on the form, so
there is nothing to point at another student.

**Can I replace a document instead of deleting and re-uploading?** Upload the
new one and remove the old one. There is no in-place version history.

**Who verifies my documents?** The administration office. AIMS stores them; it
does not judge them.
