# Results, GPA and grading

## The grading scale

| Grade | Percentage | Grade points |
|---|---|---|
| A | 85.00 and above | 4.00 |
| B | 70.00 – 84.99 | 3.00 |
| C | 60.00 – 69.99 | 2.00 |
| D | 50.00 – 59.99 | 1.00 |
| F | below 50.00 | 0.00 |

**Pass mark: 50%** — the lowest percentage that earns any grade points, which
is grade D.

This scale is stored as data, not written into the software, so if the institute
changes its thresholds the change takes effect everywhere at once. Any grade the
assistant reports is resolved against the current table.

## GPA and CGPA

- **GPA** — the grade point average for one semester.
- **CGPA** — the cumulative average across all completed semesters.

Both are on a 4.00 scale.

## Result publication

A semester result has two states: **Pending** and **Published**, with a
publication timestamp.

**Students see published results only.** Until the examination section publishes
a semester, its GPA does not appear in the student portal, and the assistant
will correctly report that it has not been published rather than inventing a
figure.

Publication is done centrally for a whole semester at once, not per student.

## What a student can see

- their own GPA per semester and running CGPA
- their own published marks per subject and exam, with grade letters
- how their CGPA has moved across semesters

## What staff can see

Teachers see performance for their own classes. Admins see distributions across
the institute — for example how many students fall into each CGPA band, by
programme or semester.

## Common questions

**My result is not showing.** The semester has probably not been published yet.
Published results appear immediately; there is no separate release to the
portal.

**My CGPA looks wrong.** CGPA is computed from published semester results only.
A semester that is still pending is not included, which is the usual
explanation.

**Can I appeal a grade?** AIMS records grades; it does not manage appeals.
Contact the examination section. The assistant can show you exactly what is
recorded, which is useful evidence, but it cannot change or challenge it.
