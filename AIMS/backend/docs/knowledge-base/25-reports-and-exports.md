# Reports and exports

## What a report is

A report reads existing records and presents them grouped and totalled. It
never changes anything, and it never invents a figure — every number on a
report is counted from rows that already exist.

Reports are scoped like every other screen: you can only report on what you can
already see.

## Teacher reports

**Faculty → Reports**, covering the classes on your timetable:

- Attendance per class, and students below a threshold you choose
- Class performance: marks distribution and averages for your subjects
- Comparison across the sections you teach

A teacher cannot report on a class taught by someone else, so an
institute-wide figure is not available from this screen.

## Administrative reports

**Admin → Reports**, institute-wide:

- Enrolment by programme, batch, section and semester
- Attendance across programmes and departments
- Examination and result summaries, including pass rates
- Fee collection: billed, collected, outstanding and overdue
- Account and credential status

## Exporting

Where a report offers an export, it produces the rows currently shown — the
same filters, the same date range. Exporting does not widen the scope: an
export of a teacher's report contains that teacher's classes only.

An export is a snapshot, not a live document. Re-run it to refresh it.

## Reports and AI Analytics

They overlap deliberately and are used differently.

A **report** is a fixed, reviewed layout for a question the institute asks
every term — you trust its shape and read the numbers.

**AI Analytics** answers a question nobody built a screen for. It generates a
query, runs it, and returns rows. Use it for the one-off; use a report for the
recurring.

Both read the same database, so a discrepancy between them means the filters
differ, not that one of them is wrong.

## Why does a percentage on a report differ from what I counted?

Almost always one of three things, all documented under *Attendance*:

- Late sessions count as attended in the standard figure but not the strict one
- Holiday sessions are excluded from the denominator entirely
- The date range on the report is not the range you counted

## Common questions

**Can I schedule a report to email itself?** No. Reports are run on demand.

**Can a teacher export the full institute attendance?** No — the export carries
the same scope as the screen.

**Why is a student missing from my report?** They are not on a roster of yours,
or the date range excludes their records.

**Are reports live?** Yes, they read current records at the moment you run
them. An export taken earlier is not.
